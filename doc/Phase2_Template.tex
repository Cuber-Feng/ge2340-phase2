\section{Introduction \& Problem Recap}

The university students will receive a large volume of emails everyday, which contains assignment / quiz / exam announcement, event invitation, security alert, bank statement notification, promotion, etc. Spending time on checking these emails can be annoying. And the performance of filter function by email apps like Gmail and Outlook is not good enough. After checking these emails, make it to the schedule can also be another issues to the university students.

The project will contains classification of the emails, summarize an email from paragraph form to bullet-point form, integrate different emails to generate a schedule. But we will not make an agent to help users to write emails.

The inputs is the email contents, and the output will be the summary (category, bullet-points, etc.) of each email, the schedule created by the AI. As the project is highly related to the campus and student life, it should have a better performance on the typical emails which students receives. To evaluate the performance, we can apply the precision, recall and other measurement to find the difference of performance between different solutions.
